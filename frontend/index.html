What this checks

  • Missing signature verification : order completion code that never checks a signature or HMAC before marking an order paid.
  • Exposed secret key : secret-looking values hardcoded into source, especially code that ships to a browser or gets bundled into a mobile app.
  • Missing webhook signature check : webhook/callback handlers that trust the payload without verifying a signature header.
  • Missing amount validation : order completion logic that never compares the confirmed amount to the amount stored at order creation.
